WEBSITE OUR LITTLE LOVE STORY 🤎

ISI WEBSITE:
- index.html: isi tulisan dan susunan elemen website.
- style.css: warna, layout, ukuran, dan animasi.
- script.js: fungsi tombol, pesan rahasia, kucing, surat, dan musik.
- images/: tempat menyimpan foto.
- music/lagu.mp3: file musik yang akan diputar.

CARA PAKAI:
1. Ekstrak ZIP ini.
2. Buka folder website_mocha_cinta.
3. Klik dua kali index.html untuk membuka website.
4. Foto ada di folder images. Nama file foto bisa disesuaikan di index.html.
5. File musik ada di music/lagu.mp3. Ganti file itu dengan lagu MP3 pilihanmu dan gunakan nama yang sama.
6. Saat tombol pembuka diklik, website utama akan muncul dan browser akan mencoba memutar musik.

CARA EDIT:
- Mau ubah kata-kata: buka index.html, lalu cari teks yang mau diganti.
- Mau ubah warna atau tampilan: buka style.css.
- Mau ubah fungsi tombol atau pesan rahasia: buka script.js.

Catatan:
- Kode sudah dirapikan dengan baris-baris terpisah supaya lebih mudah dibaca dan diedit.
- Musik otomatis hanya bisa dimulai setelah tombol pembuka diklik karena aturan autoplay browser.

Tema pembuka: arsip cinta terkunci dengan kunci/gembok. Musik mulai dicoba diputar setelah tombol BUKA GEMBOKNYA ditekan.
